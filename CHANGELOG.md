# Changelog

## 1.0.0 — English edition

Independent English desktop edition based on upstream BeefTV v2.2.1 (`c01e37b2436d68cc0c28fbaabfad23c341bf15ea`).

- Desktop UI strings and Ant Design locale are English.
- Project guides (README, quick start, contributing, security, conduct, agent rules, docs index) are English.
- Original Chinese documents are kept in `archive/zh/`.
- Longer technical manuals under `docs/content/` are still the upstream Chinese text. Translating them is later work.
- Backend messages, agent prompts, and skills are still Chinese. See `docs/BACKEND_I18N_PLAN.md`.
- Windows installer is published as BeefTV English 1.0.0. It is unsigned.

The upstream Chinese changelog through v2.2.1 is archived at [archive/zh/CHANGELOG.md](archive/zh/CHANGELOG.md).
