# Install BeefTV

The installation package does not use a paid code signing certificate. Windows may display an "Unknown Publisher" or SmartScreen prompt; macOS may require allowing it in System Settings → Privacy & Security. Devices that are restricted by organizational policy or Smart App Control may not function. Please only download from BeefTV official website or official GitHub Releases.

- Windows: Run `BeefTV-vX.Y.Z-windows-amd64-setup.exe`. After opening, directly confirm the installation location and you can install it with one click. The default is `%LOCALAPPDATA%\Programs\BeefTV`. If you overwrite the installation, the last location will be used. Regardless of whether you choose the root directory of the drive letter or the folder, the `BeefTV` subdirectory under it will be automatically loaded. During installation, the running old version of BeefTV will be automatically closed, and a start menu and desktop shortcut will be created by default. You can directly check to start after completion. The installation package runs with the current user rights and does not require administrator rights, so it cannot write to locations such as `Program Files`. WebView2 is a running dependency. If it is missing, the application will prompt you to download and install it.
- macOS: Open `.dmg` of the corresponding chip, drag `BeefTV.app` to "Applications", exit the disk image and start from "Applications". If there is an existing version, exit BeefTV first and then replace the application.
- Ubuntu 24.04 x64: After downloading `.deb`, run `sudo apt install ./BeefTV-vX.Y.Z-linux-amd64.deb` and launch it from the application menu. Download a new version of DEB and install it again to upgrade; DEB does not use automatic in-app updates.

ZIP is still available for portable use and in-app updates. Windows/macOS can continue to use in-app updates after installation. Users of the old ZIP should first exit the application, install the new package and then start it with the same system account; confirm that the old projects and materials are normal before deleting the old program directory.

The workspace is saved before in-app updates. If saving fails, you can choose "Return to processing", "Retry saving" or "Update anyway". "Update anyway" will close and restart the application, and unsaved modifications may be lost; while there is still writing in progress, you need to wait until the saving is completed before updating.

If you are prompted that the old program folder is occupied by other programs during Windows overlay installation, please close the terminal or external program that is using the directory, and then click "Retry". If it still fails, you can cancel the installation; if it prompts that the original program cannot be restored, please keep the backup folder in the prompt and do not delete it manually. The log of each installation is located at `%LOCALAPPDATA%\BeefTV\Installer\*.log`. You can hand this log to customer service to help confirm the failed steps and Windows error codes. The log contains the local installation path, please only send it to trusted support personnel.

Projects, assets, drafts, and settings are stored in separate user directories by default: Windows `%AppData%\BeefTV`; macOS `~/Library/Application Support/BeefTV`; Linux `~/.config/BeefTV` (follows `XDG_CONFIG_HOME`). Installation, overinstallation, and uninstallation do not delete these directories. Windows' WebView2 cache `%AppData%\BeefTV.exe` is also retained.

If you have specified a directory via `CANVAS_DESKTOP_DATA_DIR` or `--data-dir`, you still need to use the same directory after installation; do not put working data into the program installation directory. The installation package will not relocate custom directories, nor will it automatically retrieve lost files.
