# Agnes Image interface fields

## Protocol Identity

- Plugin ID: `agnes-image`.
- Provider ID: `agnes-image`.
- Abilities: `image`.
-Default Base URL: `https://api.agnes-ai.cn`.
- Authentication driver: `bearer`.
- Create: `POST /v1/images/generations`.
- Life cycle: synchronous response.

## Configuration fields

| Field | Type | Required | Meaning |
| --- | --- | --- | --- |
| `apiKey` | secret | Yes | API Key |

## Unified field mapping

| Uniform Fields | Type | Required | Upstream Mapping | Description |
| --- | --- | --- | --- | --- |
| `model` | string | Yes | `model` | Image model ID. |
| `prompt` | string | Yes | `prompt` | Picture prompt word. |
| `images` | media[] | No | `provider image/reference fields` | Reference picture or edit source picture, role is determined by the business layer. |
| `imageCount` | integer | No | `n/sample_count` | Output quantity. |
| `aspectRatio` | string | No | `size/aspect_ratio` | Scale or size, semantics are specified by the protocol. |
| `resolution` | string | No | `resolution/imageSize` | Resolution level. |
| `quality` | string | No | `quality` | Quality level. |
| `providerOptions` | object | No | `provider-specific fields` | Vendor extension field within the plug-in namespace. |

## Provider extension key

- `providerOptions.agnes-image.response_format`

Dynamic models or workflows are allowed to use the complete `parameters/input/extra_body` object declared by the document; this object is the open schema of the protocol itself and will not be tailored by the host.

## Responses and Errors

The plug-in maps the upstream task/status/text/media/usage to a unified result. Ephemeral media URLs are marked as ephemeral and are immediately downloaded for persistence by the host. HTTP errors, business code and error objects maintain failure semantics and are not packaged as success.

## Compatibility boundary

Agnes official image endpoint, returned synchronously. Vincentian pictures and Tushengtu share /v1/images/generations: If you do not pass image, it will be a Wensheng image, and if you pass image, it will be a Tusheng image or a combination of multiple images. size is required, take the 1K/2K/3K/4K range or WxH exact size; the screen ratio uses an independent ratio field. The reference image is placed in extra_body.image and supports public HTTPS URL or Data URI Base64. The top-level response_format is an officially listed wrong way of writing, and the output format can only be declared in extra_body.response_format. This endpoint does not accept n. A single request will return a fixed picture. When multiple pictures are needed, the upper layer will split it into multiple tasks.
