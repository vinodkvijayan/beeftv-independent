# Google Gemini Image interface fields

## Protocol Identity

- Plugin ID: `google-gemini-image`.
- Provider ID: `gemini-image`.
- Abilities: `image`.
-Default Base URL: `https://generativelanguage.googleapis.com`.
- Authentication driver: `google-api-key`.
- Create: `POST /v1beta/models/{{model}}:generateContent`.
- Life cycle: synchronous response.

## Configuration fields

| Field | Type | Required | Meaning |
| --- | --- | --- | --- |
| `apiKey` | secret | Yes | API Key |

## Unified field mapping

| Uniform Fields | Type | Required | Upstream Mapping | Description |
| --- | --- | --- | --- | --- |
| `model` | string | Yes | `model` | Image model ID. |
| `prompt` | string | Yes | `prompt` | Picture prompt word. |
| `images` | media[] | No | `provider image/reference fields` | Reference picture or edit source picture, role is determined by the business layer. |
| `imageCount` | integer | No | `n/sample_count` | Output quantity. |
| `aspectRatio` | string | No | `size/aspect_ratio` | Scale or size, semantics are specified by the protocol. |
| `resolution` | string | No | `resolution/imageSize` | Resolution level. |
| `quality` | string | No | `quality` | Quality level. |
| `providerOptions` | object | No | `provider-specific fields` | Vendor extension field within the plug-in namespace. |

## Response mapping field-by-field list

| Mapping location | Upstream path or transformation expression |
| --- | --- |
| `response.status` | `"succeeded"` |

| `response.errorPaths[0]` | `"error.code"` |
| `response.messagePaths[0]` | `"error.message"` |

## Responses and Errors

The plug-in maps the upstream task/status/text/media/usage to a unified result. Ephemeral media URLs are marked as ephemeral and are immediately downloaded for persistence by the host. HTTP errors, business code and error objects maintain failure semantics and are not packaged as success.

## Compatibility boundary

imageSize only maps 1K/2K/4K; unknown quality values (e.g. video resolution 720) must be omitted. Multi-graph output is created one-by-one by the host and does not map candidateCount.
