# DashScope Wan Video interface fields

## Protocol Identity

- Plugin ID: `dashscope-wan-video`.
- Provider ID: `dashscope-wan-video`.
- Abilities: `video`.
-Default Base URL: `https://dashscope.aliyuncs.com`.
- Authentication driver: `bearer`.
- Create: `POST /api/v1/services/aigc/video-generation/video-synthesis`.
- Query: `GET /api/v1/tasks/{{taskId}}`.

## Configuration fields

| Field | Type | Required | Meaning |
| --- | --- | --- | --- |
| `apiKey` | secret | Yes | API Key |

## Unified field mapping

| Uniform Fields | Type | Required | Upstream Mapping | Description |
| --- | --- | --- | --- | --- |
| `model` | string | Yes | `model` | Video model ID. |
| `prompt` | string | Yes | `prompt/content/input` | Video prompt word. |
| `images` | media[] | No | `first/last/reference image` | Explicit role Image input. |
| `videos` | media[] | No | `reference video` | Reference video. |
| `audios` | media[] | No | `reference audio/voice` | Reference audio or tone. |
| `duration` | integer | No | `duration/seconds` | Duration in seconds. |
| `aspectRatio` | string | No | `ratio/aspect_ratio/size` | Aspect ratio or size. |
| `resolution` | string | No | `resolution` | Resolution level. |
| `generateAudio` | boolean | No | `generate_audio` | Whether to generate audio. |
| `watermark` | boolean | No | `watermark` | Watermark switch. |
| `providerOptions` | object | No | `provider-specific fields` | Vendor extension field within the plug-in namespace. |

## Responses and Errors

The plug-in maps the upstream task/status/text/media/usage to a unified result. Ephemeral media URLs are marked as ephemeral and are immediately downloaded for persistence by the host. HTTP errors, business code and error objects maintain failure semantics and are not packaged as success.

## Compatibility boundary

This package only represents the above line protocol profile; other endpoint, cloud zone or gateway packages of the same brand must use independent plug-ins and cannot be guessed based on the model name.
