# Pika via fal.ai interface field

## Protocol Identity

- Plugin ID: `pika-via-fal`.
- Provider ID: `pika-via-fal`.
- Abilities: `video`.
-Default Base URL: `https://queue.fal.run`.
- Authentication driver: `bearer`.
- Create: `POST /{{model}}`.
- Query: `GET /{{request.providerOptions.pika-via-fal.statusPath}}`.

| Field | Type | Required | Meaning |

| `apiKey` | secret | Yes | API Key |

## Responses and Errors

The plug-in maps the upstream task/status/text/media/usage to a unified result. Ephemeral media URLs are marked as ephemeral and are immediately downloaded for persistence by the host. HTTP errors, business code and error objects maintain failure semantics and are not packaged as success.

## Compatibility boundary

This is a runtime/workflow protocol, and model fields are determined by endpoint, version, or workflow schema. Plugins do not forge fixed model fields; providerOptions.input/workflow/prompt is the complete request object, and the actual access version is locked by the conformance fixture.
