# OpenAI Chat Completions

This directory is the BeefTV declarative protocol plug-in source code. The backend is loaded from the generated `openai-chat-completions.beeftv-plugin` package and does not rely on the system's built-in `host:` adapter.

This plug-in is maintained by BeefTV Contributors and is used to adapt to OpenAI related service interfaces; it does not mean that BeefTV has an affiliation, authorization or cooperative relationship with the service provider.

See [docs/interface.md](docs/interface.md) for the complete interface.
