# Google Gemini Veo interface fields

> Official service status: Google has stopped the Gemini API's Veo preview model (`veo-3.1-*-preview`, `veo-3.1-lite-generate-preview` was closed on 2026-10-22). The official models of Veo 3.0 and 2.0 were also closed on 2026-06-30. The official recommendation is to use Gemini Omni Flash instead (the interface is different and not covered by this agreement).
> Therefore, this protocol is only available in two situations: third-party relays that still forward the `predictLongRunning` interface with the same name; or models and areas that have not been closed. Generating Veo videos directly using ordinary Gemini API Keys is not guaranteed to be available.
> This agreement will remain as it is and will not be deleted due to official suspension, nor does it mean that the official link is still in service.

## Protocol Identity

- Plugin ID: `google-gemini-veo`.
- Provider ID: `gemini-veo`.
- Abilities: `video`.
-Default Base URL: `https://generativelanguage.googleapis.com`.
- Authentication driver: `google-api-key`.
- Create: `POST /v1beta/models/{{model}}:predictLongRunning`.
- Query: `GET /v1beta/{{taskId}}`.

## Provider extension key

- `providerOptions.gemini-veo.negativePrompt`
- `providerOptions.gemini-veo.personGeneration`
- `providerOptions.gemini-veo.seed`

Dynamic models or workflows are allowed to use the complete `parameters/input/extra_body` object declared by the document; this object is the open schema of the protocol itself and will not be tailored by the host.

## Response mapping field-by-field list

| Mapping location | Upstream path or transformation expression |
| --- | --- |
| `response.taskId` | `{"$coalesce":[{"$ref":"response.name"},{"$ref":"taskId"}]}` |
| `response.status` | `{"$if":{"condition":{"$ref":"response.error"},"then":"failed","else":{"$if":{"condition":{"$ref":"response.done"},"then":"succeeded","else":"processing"}}}}` |

| `response.videos` | `{"$coalesce":[{"$ref":"response.response.generateVideoResponse.generatedSamples"},{"$ref":"response.response.generatedVideos"},{"$ref":"response.response.videos"}]}` |
| `response.errorPaths[0]` | `"error.code"` |
| `response.resultEphemeral` | `true` |

## Responses and Errors

The plug-in maps the upstream task/status/text/media/usage to a unified result. Ephemeral media URLs are marked as ephemeral and are immediately downloaded for persistence by the host. HTTP errors, business code and error objects maintain failure semantics and are not packaged as success.

## Compatibility boundary

This package only represents the above line protocol profile; other endpoint, cloud zone or gateway packages of the same brand must use independent plug-ins and cannot be guessed based on the model name.
