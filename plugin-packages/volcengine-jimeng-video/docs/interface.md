# Volcengine Jimeng Video interface fields

## Protocol Identity

- Plugin ID: `volcengine-jimeng-video`.
- Provider ID: `volcengine-jimeng-video`.
- Abilities: `video`.
-Default Base URL: `https://visual.volcengineapi.com`.
- Authentication driver: `volcengine-v4`.
- Create: `POST /`.
- Query: `POST /`.

## Configuration fields

| Field | Type | Required | Meaning |
| --- | --- | --- | --- |
| `apiKey` | secret | Yes | API Key |
| `secretKey` | secret | Yes | Secret Key |

## Responses and Errors

The plug-in maps the upstream task/status/text/media/usage to a unified result. Ephemeral media URLs are marked as ephemeral and are immediately downloaded for persistence by the host. HTTP errors and error objects maintain failure semantics and are not packaged as success; `10000` in the business code is the success code declared by the protocol and is not considered a failure. Other business codes still fail.

## Compatibility boundary

The line protocol is converged according to Jimeng's official video interface: only req_key, prompt, image_urls, aspect_ratio, frames, and resolution are sent when creating the text; the official expression is frames=24*seconds+1 to express the duration (121=5 seconds, 241=10 seconds), and only two levels of 5 seconds and 10 seconds are provided, and the other seconds are the nearest one. req_json is the configuration string of the query request, which is only sent during poll. The business success code is code=10000. The plug-in explicitly declares successCodes and will not judge the completed task as a failure. The resolution is determined by req_key, and resolution is only used as a transparent transmission and is not derived.
