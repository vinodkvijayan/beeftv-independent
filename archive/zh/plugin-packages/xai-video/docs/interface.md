# xAI Video interface fields

## Protocol Identity

- Plugin ID: `xai-video`.
- Provider ID: `xai-video`.
- Abilities: `video`.
-Default Base URL: `https://api.x.ai`.
- Authentication driver: `bearer`.
- Create: `POST /v1/videos/generations`, the official only returns `request_id`.
- Query: `GET /v1/videos/{{taskId}}`, the official return is `status` and `video.url`.
- Status: `pending`/`done`/`failed`.
- Result: Official `video.url`.

## Configuration fields

| Field | Type | Required | Meaning |
| --- | --- | --- | --- |
| `apiKey` | secret | Yes | API Key |

## Provider extension key

- No additional expansion keys.

Dynamic models or workflows are allowed to use the complete `parameters/input/extra_body` object declared by the document; this object is the open schema of the protocol itself and will not be tailored by the host.

| `response.errorPaths` | `["error.code"]` |
| `response.resultEphemeral` | `true` |

## Responses and Errors

The plug-in maps the upstream task/status/text/media/usage to a unified result. Ephemeral media URLs are marked as ephemeral and are immediately downloaded for persistence by the host. HTTP errors, business code and error objects maintain failure semantics and are not packaged as success.

## Compatibility boundary

This profile corresponds to `POST /v1/videos/generations` and `GET /v1/videos/{request_id}` of Imagine API, and only sends `model`, `prompt`, `duration`, `aspect_ratio`, `resolution`, `image` and `reference_images`. If the duration is not specified, the official default is 8 seconds. Other endpoints (video editing, video continuation, voice reference) or gateway packaging of the same brand must use independent plug-ins and cannot be guessed based on the model name.
