# Google Gemini generateContent

This directory is the BeefTV declarative protocol plug-in source code. The backend is loaded from the generated `google-gemini-generate-content.beeftv-plugin` package and does not rely on the system's built-in `host:` adapter.

This plug-in is maintained by BeefTV Contributors and is used to adapt to Google-related service interfaces; it does not mean that BeefTV has an affiliation, authorization or cooperative relationship with the service provider.

See [docs/interface.md](docs/interface.md) for the complete interface.
