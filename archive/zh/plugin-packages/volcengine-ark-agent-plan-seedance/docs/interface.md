# Volcengine Ark Agent Plan Seedance interface fields

## Protocol Identity

- Plugin ID: `volcengine-ark-agent-plan-seedance`.
- Provider ID: `volcengine-ark-agent-plan-video`.
- Abilities: `video`.
-Default Base URL: `https://ark.cn-beijing.volces.com`.
- Authentication driver: `bearer`.
- Create: `POST /api/plan/v3/contents/generations/tasks`.
- Query: `GET /api/plan/v3/contents/generations/tasks/{{taskId}}`.
- Cancellation: `DELETE /api/plan/v3/contents/generations/tasks/{{taskId}}`.

## Configuration fields

Materials support public URLs, Base64 data URLs and authorized `asset://` material IDs; local materials are read and sent by the client, and there is no need to configure a public material server. The number of materials, duration and generation mode are subject to the capabilities of the selected model. The plug-in does not use a fixed 9/3/3 limit. The minimum length of native audio is 2 seconds; Seedance 2.5 supports pure audio input by default, and 2.0 needs to provide images or videos at the same time. Explicitly configured capabilities take precedence over defaults. Duration `-1` is only used when the model capability allows, and the original value is retained when submitting.

| Field | Type | Required | Meaning |
| --- | --- | --- | --- |
| `apiKey` | secret | Yes | API Key |

## Responses and Errors

The plug-in maps the upstream task/status/text/media/usage to a unified result. Ephemeral media URLs are marked as ephemeral and are immediately downloaded for persistence by the host. HTTP errors, business code and error objects maintain failure semantics and are not packaged as success.

## Compatibility boundary

Agent Plan exclusive access: create/query/cancel via /api/plan/v3/contents/generations/tasks; the request body is consistent with the official Seedance protocol, but the Agent Plan exclusive API Key and AFP quota must be used, and cannot be mixed with the /api/v3 official Key.
