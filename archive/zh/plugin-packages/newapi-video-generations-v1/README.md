# NewAPI Video Generations Channel 2

This directory is the BeefTV declarative protocol plug-in source code. The backend is loaded from the generated `newapi-video-generations-v1.beeftv-plugin` package and does not rely on the system's built-in `host:` adapter.

This plug-in is maintained by BeefTV Contributors and is used to adapt to NewAPI related service interfaces; it does not mean that BeefTV has an affiliation, authorization or cooperative relationship with the service provider.

See [docs/interface.md](docs/interface.md) for the complete interface.
