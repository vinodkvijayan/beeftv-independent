# DashScope Qwen / Wan Image interface fields

## Protocol Identity

- Plugin ID: `dashscope-qwen-image`.
- Provider ID: `dashscope-qwen-image`.
- Abilities: `image`.
-Default Base URL: `https://dashscope.aliyuncs.com`.
- Authentication driver: `bearer`.
- Create: `POST /api/v1/services/aigc/image-generation/generation`.
- Query: `GET /api/v1/tasks/{{taskId}}`.

## Configuration fields

| Field | Type | Required | Meaning |
| --- | --- | --- | --- |
| `apiKey` | secret | Yes | API Key |

## Unified field mapping

| Uniform Fields | Type | Required | Upstream Mapping | Description |
| --- | --- | --- | --- | --- |
| `model` | string | Yes | `model` | Image model ID. |

## Responses and Errors

The plug-in maps the upstream task/status/text/media/usage to a unified result. Ephemeral media URLs are marked as ephemeral and are immediately downloaded for persistence by the host. HTTP errors, business code and error objects maintain failure semantics and are not packaged as success.

## Compatibility boundary

Bailian multi-modal image endpoint (image-generation asynchronous task). Vincentian pictures and Tusheng pictures share the same entrance: if no image is passed, it is Vincentian pictures, and if 1-3 images are passed, it is Tusheng pictures. The reference image is transmitted via input.messages[].content[].image (Base64 data URL is preferred) and OpenAI’s /v1/images/edits multipart is not used. size uses "width*height", unregistered gears are omitted and automatically recommended by the model; enable_thinking is fixed to false because the official requires non-streaming calls to turn off thinking mode.
