# Kling Video interface fields

## Protocol Identity

- Plugin ID: `kling-video`.
- Provider ID: `kling-video`.
- Abilities: `video`.
-Default Base URL: `https://api-beijing.klingai.com`.
- Authentication driver: `jwt-hs256`.
- Create: `POST /v1/videos/text2video` (automatically cut to `POST /v1/videos/image2video` when adding a picture).
- Query: `GET /v1/videos/text2video/{{taskId}}` (`GET /v1/videos/image2video/{{taskId}}` with picture).

## Configuration fields

| Field | Type | Required | Meaning |
| --- | --- | --- | --- |
| `apiKey` | secret | Yes | Access Key / API Key |
| `secretKey` | secret | No | Secret Key |

| Uniform Fields | Type | Required | Upstream Mapping | Description |

| `providerOptions` | object | No | `provider-specific fields` | Vendor extension field within the plug-in namespace. |

## Provider extension key

- `providerOptions.kling-video.body`
- `providerOptions.kling-video.extra_body`
- `providerOptions.kling-video.parameters`

Dynamic models or workflows are allowed to use the complete `parameters/input/extra_body` object declared by the document; this object is the open schema of the protocol itself and will not be tailored by the host.

| `response.errorPaths[0]` | `"error.code"` |
| `response.resultEphemeral` | `true` |

## Responses and Errors

The plug-in maps the upstream task/status/text/media/usage to a unified result. Ephemeral media URLs are marked as ephemeral and are immediately downloaded for persistence by the host. HTTP errors, business code and error objects maintain failure semantics and are not packaged as success.

## Compatibility boundary

The protocol's model-level fields change quickly or depend on cloud resource configuration. The plug-in fixed line protocol entry and unified fields, the complete vendor object is passed in through parameters/input/extra_body of providerOptions.kling-video; text/image/multi-image task. When the corresponding authentication driver is not configured, the cloud signature type entry will explicitly fail and will not pretend to be a Bearer success.
