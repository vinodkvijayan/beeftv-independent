# Full slot demonstration skills

When the user wants to verify the plug-in tool, test the canvas slot node, or check whether the plug-in and the assistant are connected:

1. Call the `slot_test_ping` tool and pass in the greeting message `message`.
2. If the user requires placing test nodes on the canvas, set `createNode` to `true`.
3. Report the tool echo results and new node status to the user.
