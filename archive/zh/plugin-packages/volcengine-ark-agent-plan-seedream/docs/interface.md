# Volcengine Ark Agent Plan Seedream Images interface fields

## Protocol Identity

- Plugin ID: `volcengine-ark-agent-plan-seedream`.
- Provider ID: `volcengine-ark-agent-plan-image`.
- Abilities: `image`.
-Default Base URL: `https://ark.cn-beijing.volces.com`.
- Authentication driver: `bearer`.
- Create: `POST /api/plan/v3/images/generations`.
- Life cycle: synchronous response.

## Configuration fields

| Field | Type | Required | Meaning |
| --- | --- | --- | --- |
| `apiKey` | secret | Yes | API Key |

| Uniform Fields | Type | Required | Upstream Mapping | Description |

| `response.messagePaths[0]` | `"error.message"` |

## Responses and Errors

The plug-in maps the upstream task/status/text/media/usage to a unified result. Ephemeral media URLs are marked as ephemeral and are immediately downloaded for persistence by the host. HTTP errors, business code and error objects maintain failure semantics and are not packaged as success.

## Compatibility boundary

Agent Plan exclusive access: The request path is /api/plan/v3/images/generations, and the Agent Plan console exclusive API Key must be used; the request body is consistent with the official Seedream protocol, but the voucher and quota are settled according to the AFP package and cannot be mixed with the /api/v3 official Key.
