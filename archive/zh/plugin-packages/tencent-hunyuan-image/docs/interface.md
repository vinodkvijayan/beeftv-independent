# Tencent Hunyuan picture interface field

## Protocol Identity

- Plugin ID: `tencent-hunyuan-image`.
- Provider ID: `tencent-hunyuan-image`.
- Abilities: `image`.
-Default Base URL: `https://hunyuan.tencentcloudapi.com`.
- Authentication driver: `tc3`.
- Create: `POST /`.
- Query: `GET /`.

| Field | Type | Required | Meaning |

| `apiKey` | secret | Yes | SecretId |
| `secretKey` | secret | Yes | SecretKey |

## Responses and Errors

The plug-in maps the upstream task/status/text/media/usage to a unified result. Ephemeral media URLs are marked as ephemeral and are immediately downloaded for persistence by the host. HTTP errors, business code and error objects maintain failure semantics and are not packaged as success.

## Compatibility boundary

The protocol's model-level fields change quickly or depend on cloud resource configuration. Plug-in fixed line protocol entry and unified fields, the complete vendor object is passed in through parameters/input/extra_body of providerOptions.tencent-hunyuan-image; TC3 Action task. When the corresponding authentication driver is not configured, the cloud signature type entry will explicitly fail and will not pretend to be a Bearer success.
